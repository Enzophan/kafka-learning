# Order App (Node.js + TypeScript)

Minimal order API using Express and TypeScript.

Quick start

Install dependencies:

```bash
npm install
```

Run in development (auto-restart):

```bash
npm run dev
```

Build and run:

```bash
npm run build
npm start
```

API endpoints
- `GET /orders` — list orders
- `GET /orders/:id` — get order
- `POST /orders` — create order (JSON body: item, qty, price)
- `PUT /orders/:id` — update order
- `DELETE /orders/:id` — delete order
